IP-BASED WEBSITE ACCESS CONTROL

Keep sensitive sites available only on the connections you trust.

Kill Switch lets you allow or limit domains and individual pages based on your public IP. It is useful for VPN safeguards, trusted-network rules, and focused access control.

HOW IT WORKS

Local rules, one small lookup.

When rules need evaluation, Kill Switch checks the public IP reported by api.ipify.org. Website targets and configured rules remain local to the browser.

If a lookup fails, a previously verified IP may be used. If no verified IP is available, configured targets remain blocked until the IP can be checked.
