# Screenshot plan and captions

Use current captures of the WXT popup and Manage rules page at 1280x800 or 640x400. Keep the extension UI readable, show real controls, and avoid private URLs or personal IP addresses.

1. **Popup status** — “See whether the current page is allowed, limited, or outside your rules.”
2. **Quick actions** — “Allow or limit a whole site or only the current page.”
3. **Searchable rules** — “Find a domain, page, or IP across a large rule list.” Show the `1 of 100 rules` count when possible.
4. **IP conditions** — “Use multiple IPv4 conditions and `!` exclusions for network-specific access.”
5. **Privacy status** — “Rules stay in the browser; only the necessary public-IP lookup leaves the device.”

The Store dashboard should contain no screenshot that shows a stale label, a fake status, a private destination, or an older interface.
