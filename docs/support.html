SUPPORT

Get Kill Switch working the way you expect.

Use the guide below for setup and the most common rule and IP lookup questions. If something still fails, open a GitHub issue with the browser, extension version, and a description of the rule pattern involved. Do not include private URLs or IP addresses in a public issue.

Quick start

  1. Install the extension and open a normal http or https page.
  2. Open the Kill Switch popup and choose Allow site, Limit site, Allow page, or Limit page.
  3. Open Manage rules to edit targets and IP conditions. Search works across domains, page URLs, and IP values.
  4. Save changes, then reload the tab if the page was already open.

Rule format

Use a hostname such as example.com for a domain. Use a full URL such as https://example.com/private for a page path. Enter multiple IPv4 values separated by commas. Prefix an IP with ! to limit that target when the public IP matches it.

Allow only on one IP203.0.113.10
Limit on one IP!198.51.100.20
Mixed conditions203.0.113.10, !198.51.100.20

Common questions

Why is the icon gray?

Gray means no configured rule matches the current page. Browser-internal pages such as chrome:// cannot be controlled by extension network rules.

Why is the icon red?

Red means a matching rule currently limits the page. If the IP lookup cannot be completed and no verified cached IP is available, configured targets remain blocked.

What does the IP service receive?

The extension makes a no-referrer request to api.ipify.org. That service can see the public IP and ordinary network request metadata. Your configured domains, page URLs, and rules are not sent.

How do I remove all rules?

Open Manage rules, remove each rule, then choose Save changes. The extension clears its dynamic blocking rules when no targets remain.
