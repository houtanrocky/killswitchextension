PRIVACY POLICY

Kill Switch keeps your rules local.

Last updated: October 16, 2026

What the extension processes

Kill Switch reads the active tab URL locally to decide whether a configured rule matches. Domains, page targets, IP conditions, status metadata, and the last verified IP are stored in the browser's local extension storage.

The extension does not collect browsing history, page content, account information, analytics, or tracking identifiers.

The necessary external request

To evaluate IP-based rules, the extension requests plain text from https://api.ipify.org with a no-referrer policy and cache disabled for the network request. The lookup service receives the public IP of the network making the request and normal request metadata. Kill Switch does not send your configured domains, page URLs, or rule list to that service.

If a lookup fails, the extension may use the last verified IP stored locally. If no verified IP is available, configured targets remain blocked until an IP can be checked.

Permissions

Storage
Stores rules, the last verified IP, and local status.
Tabs
Reads the active page URL locally and reloads the active tab after a manual refresh.
Declarative network rules
Applies blocking rules in the browser when a target is limited.
Website access
Allows rules to apply to configured HTTP and HTTPS destinations.

Control and contact

You can view, edit, or remove all rules from Manage rules. Uninstalling the extension removes its local storage. No account is required.

Questions can be reported through GitHub support. Do not include private URLs or IP addresses in public reports.
