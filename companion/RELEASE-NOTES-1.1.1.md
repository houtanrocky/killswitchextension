# Kill Switch Companion for Windows v1.1.1

- Keep the companion running in the notification area when the main window is closed.
- Reopen it by double-clicking the tray icon, or choose **Exit** from the tray menu to stop it safely.
- Preserve the existing Windows taskbar icon while the window is open.

The installer and sign-in startup behavior are included. Startup opens the app visibly; users still need to configure a trusted HTTPS gateway and enable the Windows egress gate before protection is active.
