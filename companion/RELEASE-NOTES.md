# Kill Switch Companion for Windows v1.0.0

- Standalone Windows rule manager with extension-compatible import and export.
- Branded application icon, visible taskbar entry, and notification-area menu for opening or exiting the app.
- Windows egress gate, local browser proxy, and HTTPS gateway request evaluation.
- Self-contained x64 executable; no .NET runtime installation required.

Full request-level protection requires a separately configured HTTPS gateway. Review `companion/README.md` for setup, network behavior, and limitations before enabling the egress gate.
