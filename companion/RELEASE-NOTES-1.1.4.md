# Kill Switch Companion for Windows v1.1.4

- Removed gateway address and access-key fields from the main window.
- Added automatic managed-service discovery and per-installation key registration.
- Added a clear consent prompt describing request data and public IP processing before protection starts.
- Added a deployable Cloudflare Worker gateway with per-device Durable Object policies.
- The managed service remains disabled until its Cloudflare Worker is deployed and its URL is published.
