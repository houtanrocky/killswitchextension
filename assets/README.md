# Chrome Web Store Assets

This folder contains HTML mockups for creating Chrome Web Store graphics.

## How to Use

1. Open each HTML file in a browser (Chrome recommended)
2. Use browser developer tools or a screenshot tool to capture at exact dimensions
3. Save as PNG or JPEG (24-bit, no alpha channel)

## Assets Needed

### ✅ Store Icon
- **File**: `img/icon-128x128-red.png` (already exists)
- **Size**: 128x128 pixels
- **Format**: PNG

### 📸 Screenshots (Required - at least 1)
- **Files**: `screenshot-1-popup.html`, `screenshot-2-options.html`, `screenshot-3-features.html`
- **Size**: 1280x800 or 640x400 pixels
- **Format**: JPEG or 24-bit PNG (no alpha)
- **Instructions**: 
  1. Open in browser
  2. Press F12 to open DevTools
  3. Set viewport to 1280x800
  4. Take screenshot (Ctrl+Shift+P → "Capture screenshot")
  5. Or use browser zoom to fit and screenshot

### 🎨 Small Promo Tile
- **File**: `promo-small.html`
- **Size**: 440x280 pixels
- **Format**: JPEG or 24-bit PNG (no alpha)
- **Instructions**: Same as screenshots

### 🎨 Marquee Promo Tile
- **File**: `promo-marquee.html`
- **Size**: 1400x560 pixels
- **Format**: JPEG or 24-bit PNG (no alpha)
- **Instructions**: Same as screenshots

### 🎥 Global Promo Video (Optional)
- **Format**: YouTube URL
- **Note**: You'll need to create and upload a video to YouTube

## Quick Screenshot Tips

**Using Chrome DevTools:**
1. Open HTML file
2. Press F12
3. Press Ctrl+Shift+P (Cmd+Shift+P on Mac)
4. Type "Capture screenshot"
5. Select "Capture full size screenshot"

**Using Browser Zoom:**
1. Open HTML file
2. Zoom to fit window
3. Use screenshot tool (Windows: Snipping Tool, Mac: Cmd+Shift+4)

**Using Online Tools:**
- htmlcsstoimage.com
- screenshot.guru
- html2canvas (for automated screenshots)

## Notes

- All mockups are designed at exact pixel dimensions
- Colors match your extension theme (#bc2122 red)
- Fonts use Dosis (matches your extension)
- Backgrounds use modern gradients
- All text is readable and clear
